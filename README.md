# 🏺 АГУР

**Археологический Arkanoid по мотивам древней Месопотамии.**

Ты — археолог с мячом. Перед тобой не кирпичи, а храмы, зиккураты и руины древнего мира. Разбей их — и раскопай артефакты, которые лягут в твой музей.

## ✨ Особенности

- 🗺 88 уровней в 8 регионах: Пески, Оазис, Евфрат, Степь, Загрос, Солёные равнины, Ночная пустыня, Кур
- 🏛 Музей на 216 артефактов — от Лиры Ура до табличек с клинописью
- 🎴 Колода Судеб — 42 карты восьми мастей, каждая даёт силу
- 🏆 Достижения и титулы — от «Пыль дорог» до «Царь Шумера»
- 👹 Боссы — Галла-страж, Иштар-воительница, Нергал-жнец
- ⚡ Комбо и рогалик-билды — держи серию, выбирай дары богов

## 🎮 Управление

Мышь / стрелки — платформа
Пробел — Удар Адада (при полном заряде)
P — пауза, C — колода, M — музей, T — титулы, H — как играть, Esc — меню

## 🚀 Запуск

    python server.py

Открой http://localhost:8000

## 🛠 Технологии

Чистый JavaScript (ES-модули), Canvas 2D, без зависимостей.
