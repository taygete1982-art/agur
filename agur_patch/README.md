# Патч «88 уникальных архитектур» для АГУР

## Что меняется
- **Layouts88.js (новый)** — 88 авторских раскладок 12×18. Уровни 1–10 каждого биома:
  стальной внешний каркас + тематическая постройка + камера с артефактом
  за разрушаемыми стенами (глина → серебро → золото, реген-двери, взрывные цепи,
  движущиеся стражи). Уровни 11, 22, ..., 88 — босс-арены: без стали и без артефакта.
- **LevelManager.js** — читает раскладки, отдаёт `artifactCell` (позиция артефакта)
  и помечает охрану камеры флагом `isVault`.
- **Architectures.js** — больше не перекраивает уровни: ставит артефакт
  в спроектированную камеру; на боссах ничего не делает.
- **Biomes.js** — случайная «сталь» Загроса больше не запечатывает камеру артефакта.
- **Enemies.js** — убран ложный баннер «Хранитель!» на обычных уровнях.
- **Flow.js** — исправлен индекс биома в `window.__biome`.

## Установка
Скопировать файлы из папки `js/` поверх соответствующих файлов игры
(сохранив структуру каталогов). Старый `js/levels/LevelManager.js` заменяется.

## Проверки (уже пройдены)
- все 88 раскладок уникальны;
- на каждом уровне раскопок ровно 1 артефакт, стальной каркас ≥ 20 кирпичей;
- артефакт всегда достижим мячом (путь не перекрыт сталью);
- на босс-уровнях нет ни стали, ни артефактов.

Легенда сетки: `#` сталь-стена, `T` сталь, `C` глина(2 HP), `S` серебро(3 HP),
`G` золото, `E` взрыв, `F` огонь, `R` реген, `M` движущийся, `a-d` кладка биома,
`A` камера артефакта, `.` пусто.
